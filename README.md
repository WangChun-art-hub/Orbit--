# Orbit--
一款以“声音游乐场”为概念的交互式音频创作工具。它尝试将传统音频软件中抽象的参数和线性效果器列表，转化为一个可以观察、触碰和移动的空间，让声音处理成为一种直观的探索体验。作品将滤波、失真、延迟和混响转化为不同形态的空间物体，用流动的粒子呈现信号的连接方向。用户通过左右移动物体改变效果器的串联顺序，通过前后移动调整效果强度。同一段声音会因空间布局的变化而产生不同质感，使“摆放物体”成为“塑造声音”的过程。视觉设计采用多巴胺亮色体系，以粉、青、荧光绿和黄色营造轻松、开放的氛围。设计希望降低初学者面对专业音频工具时的陌生感，鼓励用户通过拖动、试听与比较发现声音的可能性。ORBIT 支持自定义合成音源和本地音频导入，用户可以调整音源参数、搭建效果链、观察输出电平，并将处理结果导出为 WAV 文件。
